REAL AI, IN YOUR BROWSER

Let it think with you.

Download an open model once, then questions and replies are generated here on your computer. No app installation, account, API key, or subscription.

Use current Edge or Chrome with WebGPU. The first download can be several hundred MB or more. Larger models need more memory. Small models make mistakes and will not match a large hosted model's quality.

Nothing is downloaded until you choose Load AI.

Model files and the WebLLM runtime are downloaded from public servers. Your notes are passed to the model locally. Keep this file and use the same browser to reuse its cache.

Use GPT for inline questions, explanations, quizzes, follow-ups, and diagrams inside this notebook.

Use a Responses-compatible model available on your API account. The API key stays on the local backend in OPENAI_API_KEY. It is never included in this HTML, browser storage, backups, or GitHub.

GPT requires the server edition. Copy .env.example to .env locally, add your API key there, and run node server.cjs. Then open the local notebook address.

GPT starts in When you ask mode. You can enable automatic questions afterward.

Continue in your chat.

Optional fallback when the local model is off or unavailable.

The page is yours.

  1. Write in paragraphs. Press Enter for a new paragraph. Shift+Enter adds a line break.
  2. Choose Enable AI, then use a local browser model or OpenAI GPT through the server edition.
  3. In Thinks with you, pause after writing and a question appears under the passage. In When you ask, use Ask or select a passage.
  4. Open any thought to ask why, push back, or draw the idea.
  5. Set your own reviewers, note goals, and ink under preferences.

Notes save in this browser. Moving this file, switching browsers, or clearing browser data may hide or erase them. Export backups regularly. Import also accepts the earlier Thinkbook backup format.

This is an independent implementation of the workflow. Riddled's private model and account service are not included.
